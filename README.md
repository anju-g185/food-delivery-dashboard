# food-delivery-dashboard
"An interactive Food Delivery Dashboard built using python, sql and power bi to analyze sales, orders, customers, delivery performance, and restaurant insights,"
Key insights
1.Identified revenue and order trends.
2.Compared restaurant and city performance.
3.Analyzed customer behavior and repeat orders.
4.Evaluated delivery time and cancellation rates.
5.Segmented customer based on order activity.
6.Identified areas for improving delivery performance.
